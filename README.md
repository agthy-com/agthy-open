# Agthy

[Agthy](https://agthy.com) is the agentic platform: you describe a job, or start it from GitHub, a schedule, the API or your own AI agent, and a team of AI agents searches, reads, works and reports back. Any model, with every step of the work shown to you. Free to start, pay only for what you use.

## What this repository is for

This is Agthy's public home for talking with us. The product's source code is not here.

- **Request a feature:** [open a feature request](https://github.com/agthy-com/agthy-open/issues/new?template=feature_request.yml).
- **Report a bug:** [open a bug report](https://github.com/agthy-com/agthy-open/issues/new?template=bug_report.yml).
- **Follow along:** every issue is public, so you can see what others asked for and add your thumbs-up or details.

You can also ask the Wiki Specialist inside the Agthy app: its "Request a feature" and "Report a bug" shortcuts link straight to these forms.

## Before you open an issue

- One idea or one problem per issue.
- Issues are public. Never paste passwords, API keys, GitHub tokens or webhook secrets, and hide them in screenshots.
- For anything private, such as your account or billing, contact us through the email on [agthy.com](https://agthy.com) instead.
